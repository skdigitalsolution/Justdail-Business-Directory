## 3. Reliability & Next.js Performance Highlights
1. **Local Asset Serving**: Zero external network requests to third-party image CDNs during page render.
2. **Next.js `<Image>` Optimization**: Automatic WebP transcoding, responsive sizing (`sizes`), and lazy loading for off-screen cards.
3. **Robust Video Fallback**: The `<video>` tags include `poster="/images/hero-poster.jpg"` and `poster="/images/showcase-poster.jpg"`, `playsInline`, `muted`, and respect `prefers-reduced-motion` settings.
